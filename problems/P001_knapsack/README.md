# P001 · 0-1 背包

给定 `n` 件物品，第 `i` 件重量为 `weights[i]`、价值为 `values[i]`，背包容量上限为 `capacity`。
请使用 PySCIPOpt 为每件物品选择 0/1 决策变量，在总重量不超过容量的约束下最大化总价值。

## 输入 `instance`

```json
{
  "n": 5,
  "weights": [2, 3, 4, 5, 9],
  "values": [3, 4, 8, 8, 10],
  "capacity": 20
}
```

> 上述教学样例的最优总价值为 `28`。正式评测时系统会使用随机生成的多组独立算例进行测试，请通过建模求解，切勿硬编码数值。

## 输出规范

```python
{
  "status": "optimal",
  "objective": float,
  "solution": {0: 0.0, 1: 1.0, ...}  # 或长度为 n 的 list
}
```

## 提示

可通过枚举或动态规划对比验证小规模样例结果，正式实现请使用 PySCIPOpt 建模求解。
