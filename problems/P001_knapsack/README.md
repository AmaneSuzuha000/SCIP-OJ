# P001 · 0-1 背包优化（资源预算分配）

## 1. 问题背景与描述

在制造投产、项目立项与物流配载中，决策者经常面临**资源上限固定、候选项目不可拆分**的选择问题：现有 $n$ 件候选物品，第 $i$ 件（$i = 0, 1, \dots, n-1$）占用资源重量为 $w_i$、产生经济价值为 $v_i$，可用总预算（背包容量）为 $C$。

请使用 PySCIPOpt 建立混合整数线性规划模型（MILP），在总重量不超过容量上限的前提下，选出使总价值最大的物品组合。

## 2. 混合整数线性规划模型（MILP）

- **决策变量**：对每件物品引入二元变量 $x_i \in \{0, 1\}$（$i = 0, \dots, n-1$），其中 $x_i = 1$ 表示选入物品 $i$，$x_i = 0$ 表示不选。
- **目标函数**（最大化总价值）：

$$\max \sum_{i=0}^{n-1} v_i x_i$$

- **容量与整数约束**：

$$\sum_{i=0}^{n-1} w_i x_i \le C, \qquad x_i \in \{0, 1\}, \; \forall i \in \{0, \dots, n-1\}$$

## 3. `solve(instance)` 接口规范

### 输入字典 `instance`

| 字段 | 类型 | 说明与约束 |
| --- | --- | --- |
| `n` | `int` | 物品总数量（$n \ge 1$） |
| `weights` | `list[float]` | 长度为 `n` 的正重量列表 `weights[i]` |
| `values` | `list[float]` | 长度为 `n` 的非负价值列表 `values[i]` |
| `capacity` | `float` | 背包总容量上限 $C$ |

### 返回字典

```python
{
  "status": "optimal",
  "objective": float,          # 所选物品总价值 sum(values[i] * x[i])
  "solution": {0: 1.0, ...}    # 下标映射 dict（0..n-1 -> 0/1）或长度为 n 的 list
}
```

> **编码注意**：请仅在 `model.getStatus() == "optimal"`（或确有可行解）后读取变量值；`objective` 必须与 `solution` 复算得到的总价值一致。

## 4. 公开样例与本地自测对照

工作台工具栏的 **「本地自测」** 会使用下述公开教学样例检验函数接口与最优性：

```json
{
  "n": 5,
  "weights": [2, 3, 4, 5, 9],
  "values": [3, 4, 5, 8, 10],
  "capacity": 10
}
```

- **最优解**：选择下标为 `0, 1, 3` 的物品（`solution = {0: 1.0, 1: 1.0, 2: 0.0, 3: 1.0, 4: 0.0}`）
- **总重量**：$2 + 3 + 5 = 10 \le 10$（容量紧约束）
- **最优目标值**：$3 + 4 + 8 = \mathbf{15}$

> 正式提交后，云端隔离容器将生成**多组不同规模的隐藏随机算例**独立评测；请基于输入 `instance` 通用建模，切勿针对样例硬编码结果。

## 5. 四维评分细则与常见排查

| 维度 | 权重 | 核验要点 | 常见失分原因 |
| --- | ---: | --- | --- |
| **格式规范 `F`** | 10 | 返回包含 `objective` 与 `solution` 的 `dict`，目标为有限实数 | 函数名非 `solve`、缺少键或目标值出现 `NaN`/`Inf` |
| **约束满足 `C`** | 35 | 总重量 $\le C + 10^{-5}$ 且每项分量满足 $0 \le x_i \le 1$ | 容量约束方向写反（`>=`）或变量下界未限定 |
| **整数性 `I`** | 10 | 每项 $x_i \in \{0, 1\}$ 且 `objective` 与解复算价值误差 $\le 10^{-5}$ | 变量 `vtype` 误设为连续 `"C"` 而未设二元 `"B"` |
| **目标最优 `O`** | 45 | 相对隐藏算例理论最优目标值的相对差距梯度计分 | 目标函数误设为 `"minimize"` 或漏加部分物品价值项 |
