# P002 · 指派问题（Assignment）

将 \(n\) 名工人一对一指派至 \(n\) 项任务，使总指派费用最小。

## 数学模型（MIP）

- 决策变量：\(x_{ij} \in \{0,1\}\) 表示工人 \(i\) 是否执行任务 \(j\)
- 目标函数：\(\min \sum_{i,j} c_{ij} x_{ij}\)
- 每名工人恰承担一项任务：\(\sum_j x_{ij} = 1\)
- 每项任务恰由一人完成：\(\sum_i x_{ij} = 1\)

## `solve(instance)` 接口规范

输入 `instance` 字典字段如下：

| 字段 | 含义 |
| --- | --- |
| `n` | 问题规模（工人与任务数量） |
| `costs` | \(n \times n\) 费用矩阵（整数或浮点数） |

返回字典格式：

```python
{"status": "optimal" | "feasible", "objective": float, "solution": ...}
```

其中 `solution` 支持以下任意一种表达：

- 嵌套列表（\(n \times n\) 二维数组），或
- 长度为 \(n^2\) 的一维扁平列表，或
- 以 `"i,j"` / `(i,j)` 为键的字典

矩阵元素取值为 `0` 或 `1`，且自报 `objective` 须等于 \(\sum c_{ij} x_{ij}\)。

## 评分维度

依次核验：返回格式 → 行/列指派约束 → 变量整数性与目标一致性 → 相对最优目标差距。多组独立算例按算术平均计分，默认及格线 **90 分**。
