# P002 · 平衡指派优化（任务一对一匹配）

## 1. 问题背景与描述

在班组排产与运维调度中，需要将 $n$ 名作业人员（或设备）一对一分派给 $n$ 项独立任务：每位人员 $i$ 完成任务 $j$ 的成本为 $c_{ij}$。每名人员只能承担**恰好一项**任务，且每项任务必须由**恰好一名**人员完成。

请使用 PySCIPOpt 建立 0-1 整数线性规划模型，找出使总指派费用最小的最优匹配方案。

## 2. 混合整数线性规划模型（MILP）

- **决策变量**：引入二元矩阵变量 $x_{ij} \in \{0, 1\}$（$i, j \in \{0, \dots, n-1\}$），表示是否将人员 $i$ 指派至任务 $j$。
- **目标函数**（最小化总指派费用）：

$$\min \sum_{i=0}^{n-1} \sum_{j=0}^{n-1} c_{ij} x_{ij}$$

- **行指派约束**（每人恰好承担一项任务）：

$$\sum_{j=0}^{n-1} x_{ij} = 1, \qquad \forall i \in \{0, \dots, n-1\}$$

- **列指派约束**（每项任务恰好由一人完成）：

$$\sum_{i=0}^{n-1} x_{ij} = 1, \qquad \forall j \in \{0, \dots, n-1\}$$

> **性质提示**：平衡指派模型的约束系数矩阵满足**全幺模性（Totally Unimodular）**，即使将变量松弛为连续非负 $x_{ij} \ge 0$，其线性规划极点解也天然为整数；工程建模时仍建议明确声明 `vtype="B"` 以确保整数语义清晰。

## 3. `solve(instance)` 接口规范

### 输入字典 `instance`

| 字段 | 类型 | 说明与约束 |
| --- | --- | --- |
| `n` | `int` | 人员数量与任务数量（$n \ge 2$） |
| `costs` | `list[list[float]]` | $n \times n$ 费用矩阵，`costs[i][j]` 为人员 $i$ 执行任务 $j$ 的成本 |

### 返回字典

```python
{
  "status": "optimal",
  "objective": float,            # 总指派成本 sum(costs[i][j] * x[i][j])
  "solution": [[1.0, 0.0], ...]  # 支持 n×n 二维矩阵、长度为 n² 的一维列表，或 "i,j"/(i,j) 映射字典
}
```

> **编码注意**：自报 `objective` 必须与由 `solution` 复算得到的总费用 $\sum_{i,j} c_{ij} x_{ij}$ 保持一致。

## 4. 公开样例与本地自测对照

工作台工具栏的 **「本地自测」** 会使用下述 $3 \times 3$ 教学样例检验函数接口与最优性：

```json
{
  "n": 3,
  "costs": [
    [4, 2, 8],
    [2, 3, 7],
    [5, 8, 3]
  ]
}
```

- **最优匹配**：人员 `0 → 任务 1`（费用 `2`）、人员 `1 → 任务 0`（费用 `2`）、人员 `2 → 任务 2`（费用 `3`）
- **解矩阵**：`[[0, 1, 0], [1, 0, 0], [0, 0, 1]]`
- **最优目标值**：$2 + 2 + 3 = \mathbf{7}$

> 正式提交后，云端隔离容器将生成**多组不同规模的隐藏随机算例**独立评测；多组独立算例按算术平均计分，默认及格线 **90 分**。

## 5. 四维评分细则与常见排查

| 维度 | 权重 | 核验要点 | 常见失分原因 |
| --- | ---: | --- | --- |
| **格式规范 `F`** | 10 | 返回包含 `objective` 与 `solution` 的 `dict`，目标为有限实数 | `solution` 维度不是 $n \times n$ 或缺少必要字段 |
| **约束满足 `C`** | 35 | 所有行和与列和均为 $1$（容差 $10^{-5}$），且分量在 $[0, 1]$ | 只写了行约束漏写列约束，导致多人抢同一任务 |
| **整数性 `I`** | 10 | 每项 $x_{ij} \in \{0, 1\}$ 且自报 `objective` 与解矩阵成本一致 | 提取解时行列下标 `[i][j]` 颠倒导致与目标值不一致 |
| **目标最优 `O`** | 45 | 对照隐藏算例最小总成本的相对最优差距计分 | 优化方向误设为 `"maximize"`，返回最差指派方案 |
