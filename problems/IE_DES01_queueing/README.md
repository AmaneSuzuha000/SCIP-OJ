# IE-DES-01 检修工位排队离散事件仿真

## 题目背景
某城轨列车检修车间设有一个集中待检区和 $c$ 个并行检修工位。列车到达服从参数为 $\lambda$ 的泊松过程（到达间隔服从均值为 $\text{arrivalMean}$ 的指数分布）。列车在各工位的检修服务时长服从均值为 $\text{serviceMean}$ 的指数分布。排队规则为严格先到先服务（FCFS）。

为了评估工位扩容与生产线瓶颈，需要编写一个离散事件仿真求解器 `solve(instance)`，统计系统在经过指定预热期（`warmup`）后在统计窗口内的各项关键排队性能指标。

## 输入格式
评测系统向 `solve(instance)` 传入一个字典 `instance`，包含以下字段：
- `arrivalMean`: 浮点数，平均到达间隔（分钟）
- `serviceMean`: 浮点数，平均检修时长（分钟）
- `servers`: 整数，并行检修工位数 $c$
- `horizon`: 整数，总仿真时长（分钟）
- `warmup`: 整数，预热时长（分钟），预热期内发生事件不计入统计指标
- `seed`: 整数，随机数种子（32 位无符号整数）

## 输出格式
求解器必须返回一个字典，包含以下字段（浮点数或整数）：
- `avgWait`: 平均等待时间（分钟）
- `throughput`: 统计窗口内的小时吞吐率（件/小时）
- `utilization`: 工位平均综合利用率，取值范围在 $[0.0, 1.0]$
- `meanQueue`: 统计窗口内的平均排队队长（人/车）
- `meanWip`: 统计窗口内的平均在制品总数（WIP = 队中 + 工位中）
- `completions`: 统计窗口内完成检修出站的总列车数

## 评分规则
- **格式分 (F, 15分)**：返回合法字典，且包含全部 6 个必要字段，均为有限数值。
- **物理约束分 (C, 25分)**：利用率在 $[0, 1]$ 之间，平均等待、队长、完工数非负，且满足 $\text{meanWip} \ge \text{meanQueue}$。
- **一致性分 (I, 20分)**：满足守恒率与 Little's Law 检验，吞吐量与完工服务数满足 $\text{throughput} = 60 \times \text{completions} / (\text{horizon} - \text{warmup})$。
- **仿真精度分 (O, 40分)**：与平台权威仿真基准（带相同种子的事件驱动离散事件基准）核对，偏差 $\le 0.1\%$ 得满分 40 分，依次梯度递减。及格线为 90 分。
