# 出题指南（老师）

面向「文件出题」：不改站台代码也能加题。判分政策见 [判分协议-已冻结.md](./判分协议-已冻结.md)。

## 1. 目录约定

在 `problems/` 下新建 `P00x_slug/`，至少包含：

| 文件 | 作用 |
|------|------|
| `README.md` | 题面（中文） |
| `meta.json` | 判分参数 |
| `template.py` | 学生起点；必须有 `solve(instance) -> dict` |
| `gen.py` | `generate(seed) -> instance`（可委托 `judge.runner_l1`） |
| `judge.py` | `grade(result, instance, meta)`（通常委托 `judge.common`） |

然后在 `problems/index.json` 增加一条题单记录。

## 2. `meta.json` 必填字段

参考 P001 / P002：

- `id`：如 `"P002"`
- `sense`：`"maximize"` / `"minimize"`
- `eps_feas` / `eps_int` / `eps_obj`
- `time_limit_sec`
- `pass_score`：默认 **90**
- `n_instances_l1`：默认 **3**（多实例**算术平均**）
- `seed_base`：实例种子起点
- `weights`：`F/C/I/O` 分项权重（和为 90+ 即可）
- `grader`：浏览器与 Python 共用的判分器名（如 `knapsack`、`assignment`）

## 3. 实例与返回契约

`instance` 必须自带 `optimal_value`（由 `gen` 用确定性算法算出），供目标 gap 评分。  
学生 `solve` 返回：

```python
{"status": "...", "objective": float, "solution": ...}
```

判分顺序：**格式 → 可行性 → 整数性 → objective 与解一致 → 目标 gap**。不要只比对打印字符串。

## 4. L1（浏览器）镜像

若该题要在 Pages 上点「L1 练习评分」：

1. 在 `site/js/` 增加与 Python 同规则的 `*_judge.js`（生成器种子算法必须一致）。
2. 在 `site/js/app.js` 按 `meta.grader` 分发。
3. `site/index.html` 引入脚本。
4. 浏览器端通过 WebAssembly 真实执行学生代码，支持秒级反馈。

## 5. 正式成绩与平台评测（Phase 1 架构）

平台现已支持**全链路网页端作业提交与自动评测**：

1. **题目录入与作业发布**：
   - 在 `assignments` 表中插入对应记录（`course_id`, `problem_id`, `due_at`, `pass_score`, `score_policy`）。
   - 默认采用 `highest_before_due`（截止前最高分）计分规则。
2. **自动化评测流水线**：
   - 学生在网页端点击「提交正式作业」后，由 `submit-assignment` 云函数触发 `.github/workflows/grade-submission.yml`。
   - runner 检出代码并运行 `judge/runner_l2.py` 对学生代码进行性质验证判分，随后通过 HMAC-SHA256 签名回调写回数据库。
   - 教师可在 `site/teacher.html` 实时查阅班级成绩簿，并支持导出 UTF-8 CSV。
3. **出题规范**：
   - 保证 **Python `judge` 验证逻辑不依赖 SCIP 求解器**（由 `gen.py` 用确定性算法算出 `optimal_value`，`judge.py` 仅比对可行性、整数性与目标值 gap）。
   - 评测 runner 预装完整 `PySCIPOpt`，学生代码可自由调用 `from pyscipopt import Model` 建模。
   - （备用通道）原有通过 `submissions/<github_user>/<problem_id>.py` 开 PR 的工作流 `.github/workflows/l2-grade.yml` 仍作为开发者自测工具保留。

## 6. 合并前检查清单

- [ ] `index.json` 已登记  
- [ ] `meta.json` 字段齐全，`pass_score=90`，`n_instances_l1≥1`  
- [ ] 本地烟测：`python -c` 跑 `run_l1(load_solve(template), meta)` 能通过  
- [ ] 若上 L1 站：JS 种子与 Python `gen` 一致  
- [ ] README 写清 `solve` 契约与 `solution` 形状  
- [ ] 未把标准答案硬编码进前端唯一路径（性质验证 + 多 seed）
