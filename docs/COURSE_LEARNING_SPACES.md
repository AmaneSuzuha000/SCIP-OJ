# 课程空间与学习工作台

本版采用选定的任务优先设计，并将“课程空间”和“学习工作台”实现为两个真正独立的页面状态。

| 入口 | 内容 | URL |
| --- | --- | --- |
| 课程概览 | 课程路径、当前班级、案例目录、作业要求 | `index.html#course` |
| 案例目录 | 三个合成教学案例 | `index.html#course-cases` |
| 作业说明 | 实验记录与正式作业的区别 | `index.html#course-assessments` |
| 学习概览 | 检修排队任务、四步实验路径、其他案例入口 | `index.html#learn` |
| 在线做题 | 搜索、筛选题目，进入已有编程工作台 | `index.html#problem-list-section` |
| 提交记录 | 当前用户全部正式提交与评测反馈 | `index.html#submissions` |

旧的 `#list`、`#P001`、`#P002` 链接继续可用。未知题号恢复到题库。顶栏、侧栏和内容区域由同一路由状态驱动；同一时刻仅展示一个空间及一个学习视图。

课程横幅继续读取真实选课信息。全局提交历史复用原有组件与 `getMySubmissions(null)`，查询仍限制 `user_id`，并通过现有外键读取题号、班级名称和班级代码。不可见的关联信息使用明确的缺失提示，不隐藏原提交。通过状态使用服务端 `passed`，不假定所有作业通过线均为 90 分。

考试草稿在离开题目或切换题目时统一提示，取消后恢复原 URL 与编辑内容。离开题目会使尚未返回的题目、作业信息及提交历史请求失效，避免旧响应覆盖新空间。普通模式仍使用已有浏览器草稿机制。

插图为独立生成的三工位车辆部件检修场景，用于修正概念图中的串行加工设备表达。图标来自 `@phosphor-icons/core@2.1.1` 原始资源，许可证位于 `site/assets/icons/LICENSE`。

本地预览：`npm run dev -- --host 0.0.0.0 --port 4173`。预览服务器仅接受读取请求；JupyterLab/REPL 链接转到既有 Pages 版本。生产仍由原 GitHub Pages 工作流构建。

视觉对照及修订记录见根目录 `design-qa.md`。浏览器验收覆盖双空间、移动导航、旧题目链接、考试草稿取消/确认、一次离开提示、延迟作业响应、提交状态、三个仿真实验和下载回放。

本次没有数据库迁移、权限调整、评分策略或隔离评测运行器变更。匿名查询正式提交仍返回权限拒绝；真实登录账号的成绩数据未在本次视觉验收中读取。
