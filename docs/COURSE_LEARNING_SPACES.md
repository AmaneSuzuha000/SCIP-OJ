# 课程教学与拓展学习

当前分区按用途划分，覆盖此前“课程介绍 / 学习操作”的划分。初始教学目标是学生在网页完成建模、练习、正式提交与查分，教师管理班级、作业与成绩。后来增加的开放案例和进阶资源独立组织。

| 区域 | 功能 | 路由 |
| --- | --- | --- |
| 课程教学（默认） | 班级信息、教学流程与作业说明 | `#course` |
| 课程教学 | 课程题库、编程工作台、练习与正式提交 | `#problem-list-section`、`#P001`、`#P002` |
| 课程教学 | 正式提交记录、成绩与报告 | `#submissions` |
| 课程教学 | 原有 P001/P002 PySCIPOpt 配套 Notebook | `#course-labs` |
| 课程教学 | 学生指南、教师指南、教师管理 | 教学侧栏与 `teacher.html` |
| 拓展学习 | 检修排队、库存、生产线三套开放仿真 | `#learn`、`#case-library` |
| 拓展学习 | 设施选址、装箱、流水车间、随机库存 Notebook | `#learn-notebooks` |
| 拓展学习 | 官方建模示例与拓展学习指南 | 拓展侧栏与各自返回入口 |

后续修改必须保持以下边界：

1. 默认入口属于课程教学。课程首页不放拓展仿真任务；拓展页不放课程作业或成绩入口。
2. 课程题库、编辑器和提交记录在 DOM 中归属于课程教学，不能仅靠改标题或隐藏按钮模拟分区。
3. 两区分别显示导航、资源、说明与页脚；拓展区不显示班级认证、教师控制台或正式成绩面板。
4. 开放案例返回拓展学习；教师管理返回课程教学。拓展文档使用自己的导航。
5. 原有 `#list` 与题号书签继续进入课程教学；旧 `#course-cases` 书签跟随仿真内容进入拓展区。
6. 原有考试草稿保护与服务端成绩契约保留。学习用途分区不要求复制数据库、认证或求解器。

Notebook 链接按 JupyterLite 官方 `path` 参数直接打开具体文件，采用 single-document 模式。课程使用 01/02，拓展使用 03–06。构建时保留生成页的 `jupyter-config-data` 到自定义首页，修复 Lab/REPL 读取根页配置时的白屏故障；`scripts/merge_jupyter_shell.py` 与回归测试记录该契约。

视觉设计保留已选定的白底、青绿色、侧栏、任务优先布局与实际检修工位插图。分区用途更正不重新引入合并式首页。视觉验证见根目录 `design-qa.md`。
