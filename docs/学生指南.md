# 学生指南

## L1：浏览器练习（不作正式成绩）

1. 打开站点题单，进入题目。
2. 阅读题面，理解 `solve(instance)` 契约与输入输出格式。
3. 点「提交评分（L1）」：**浏览器通过 WebAssembly (WASM) 真实执行你在文本框中编写的 Python 代码**，对多个随机实例评分后取**算术平均**；≥ **90** 提示通过。
   - **首次加载提示**：首次点击判分时，浏览器需下载并初始化 Python WASM 解释器（约 6MB），可能需要数秒时间，控制台与状态栏会显示加载进度。
   - **题目模板支持**：P001（背包 DP）与 P002（指派暴力/贪心）模板为纯 Python 算法，可直接在力扣壳文本框内真跑并获得评分。
4. **全功能 PySCIPOpt 环境 (JupyterLab)**：
   - 站点已集成基于 WebAssembly 的 JupyterLite（预装 `xeus-python`、`pyscipopt`、`numpy`）。
   - 点击页面顶栏的 **「JupyterLab (PySCIPOpt)」** 即可在新标签页中打开 JupyterLab，直接在浏览器里 `from pyscipopt import Model` 建模并交互调试。
   - `content/` 内提供了 P001 与 P002 的 PySCIPOpt 建模范例 Notebook（`01_P001_knapsack_PySCIPOpt.ipynb` 与 `02_P002_assignment_PySCIPOpt.ipynb`）。
5. **L1 分数仅练习反馈**，可被本机篡改，**不作正式成绩**。

## L2：正式提交（PR + Actions）

1. Fork 本仓库（或在有写权限的分支上作业）。
2. 新建分支，放入：

   `submissions/<你的 GitHub 登录名>/<题目ID>.py`

   例如：`submissions/AmaneSuzuha000/P002.py`  
   文件内必须定义 `solve(instance)`。

3. 向 `main` 开 Pull Request（改动需触及 `submissions/**`）。
4. 等待 **L2 Grade** Action：机器人在 PR 下评论平均分与是否通过。
5. **计入成绩认 L2 评论/产物中的分数**，不认浏览器 L1。

详见 `submissions/README.md`。
