# 学生指南：SCIP-OJ 使用说明

欢迎使用 SCIP-OJ 系统建模与优化作业平台！本平台提供「**本地免配置练习**」与「**网页端一键提交正式作业**」双轨功能。

当前站点只允许已授权的 GitHub 账号登录后进入。进入「课程教学」后，先在「当前任务范围」选择教学班级；加入多个班级时不会自动替你选择。课程作业、及格线、草稿和正式提交记录都对应当前班级。选择「自主练习」可使用练习题库，该模式不计正式成绩。

题目标签和任务位置可在刷新、前进后退后恢复；从指南或实验页可通过「返回之前的页面」继续原任务。普通草稿按账号和作业分别保存；旧版无归属草稿可下载备份，不会自动混入新任务。考试模式仍不自动保存代码，离开前应先正式提交。

---

## 核心边界与要求（先读）

1. **正式成绩只认服务端评测**：浏览器内点击的「练习评分」仅供本地调试，不会作为课程正式成绩；正式成绩必须点击「正式提交」由课程评测服务判分。
2. **网页提交**：使用 GitHub 账号登录后，在题目页面提交作业并查看评测结果。
3. **学号绑定**：请务必在登录后核对并绑定你的**真实学号**与**姓名**，系统将自动对齐教师花名册并归档期末成绩。

---

## 模式一：浏览器免配置练习

1. **进入题目**：从“课程教学”进入“课程作业”，点击对应题目（如 `P001 0-1背包问题` 或 `P002 指派问题`）。
2. **编写代码**：在代码编辑框中实现 `solve(instance)` 函数，契约如下：
   ```python
   def solve(instance: dict) -> dict:
       # 根据输入 instance 进行建模与求解...
       return {
           "status": "optimal",
           "objective": float(...),
           "solution": {...}
       }
   ```
3. **点击「练习评分」**：
   - 浏览器将通过 WebAssembly (WASM) 在你的设备本地直接运行 Python 代码。
   - 对随机生成的多组测试实例进行求解与性质校验（可行性、整数性、目标 gap）。
   - 取多实例的**算术平均分**，按题目要求判断是否通过。测试期间可以停止运行并保留代码。
   - 进入网页后会自动准备环境；顶栏显示「Python 就绪」后即可测试。环境暂不可用时可点击「重试」。
4. **网络要求**：首次加载运行环境和题目需要联网；选课、正式提交和成绩查询也需要网络连接。

## 模式二：JupyterLab (PySCIPOpt) 交互式在线建模

如果题目涉及复杂的整数规划、混合整数规划（MIP）或需要调用 SCIP 优化求解器：
1. 在“课程教学”的 **「课程实验」** 中选择与 P001 / P002 配套的 Notebook，；题目工作区也提供 **「Notebook 视图」**。
2. 浏览器将打开基于 WebAssembly 构建的在线 JupyterLite 实验环境（已预装 `xeus-python`、`pyscipopt` 和 `numpy`）。
3. 无需在个人电脑配置 C/C++ 编译链与 SCIP 求解器，可直接在 Notebook 中交互验证：
   ```python
   from pyscipopt import Model

   model = Model("example")
   x = model.addVar(vtype="B", name="x")
   # 自由定义约束与目标...
   model.optimize()
   ```
4. 教学 Notebook 在同一个平台工作台内打开，使用「返回课程实验」回到课程列表。拓展模型从「拓展学习 → 优化建模」进入，返回原学习空间。题目内的 Notebook 视图会自动同步唯一的作业代码单元。

## 模式三：正式作业提交（全流程指南）

### 步骤 1：GitHub 账号登录
- 在访问页点击 **「使用 GitHub 登录」**。
- 跳转授权后返回主站，顶栏显示你的 GitHub 昵称。

### 步骤 2：绑定课程学号与真实姓名
- 首次登录后，系统会自动弹出 **「绑定课程学号与真实姓名」** 弹窗。
- 请正确填写你的**学号**（如 `20260001`）与**真实姓名**（如 `李同学`）。
- 若后续需要修改，打开右上角账号菜单里的 **「个人资料」**。

### 步骤 3：输入课程邀请码选课
- 系统弹出 **「输入课程邀请码」** 弹窗。也可以随时从账号菜单打开 **「加入课程」**。
- 输入任课教师发放的邀请码，点击「确认加入课程」。
- 加入成功后，系统自动将你的账号与教师预置的花名册进行对齐匹配。

### 步骤 4：查阅作业要求与截止时间
- 打开作业题目，代码框上方会展示当前作业考核要求：
  - **截止时间**：明确标注截止日期；若超过截止时间提交，系统将打上「迟交」标记。
  - **及格分数**：默认为 90 分。
  - **计分规则**：默认为「截止前最高分」。
  - **正式测例**：服务端权威评测所运行的独立算例数量（通常为 3 个）。

### 步骤 5：点击「正式提交（服务端评测）」
- 点击提交按钮，代码将被安全发送至服务端进行评测排队。
- 状态栏提示：`✅ 提交成功！公开编号 SUB-XXXXXXXX，已进入服务端评测队列。`
- 页面下方的 **「📜 我的提交记录」** 将自动新增一行记录，系统自适应开启后台智能轮询刷新。

### 步骤 6：查看评测流转与成绩报告
- 提交记录的状态将自动更新：
  - `⏳ 排队中` (queued) → `⚙️ 评测中` (running) → `已完成` (done)。
  - **出分展示**：达到及格线显示绿色 `100 分 ✓ 通过`。
  - **系统故障保护**：若 GitHub 评测 runner 偶发网络或环境异常，状态将显示为 `⚠️ 系统故障`。**系统故障绝对不会记为学生 0 分**，分数保留为未出分状态，可联系助教复判或稍后再次提交。
  - **查看详情**：点击操作列的「查看详情」，弹窗展示每个测试实例的具体扣分细则与耗时。

### 步骤 7：查阅课程排行榜（只读脱敏）
- 点击提交列表右上方的 **「🏆 课程排行榜」** 按钮。
- 可查阅本题目在全班学生中的最优分排行。
- **隐私保护说明**：为保障同学个人隐私，学号自动脱敏处理（例如显示为 `2026****01`）。

## 常见问题与排错

- **Q: 提示「提交正式作业前，请先在右上角绑定您的真实学号与姓名」？**
  - A: 正式成绩需归档至教务成绩单。打开账号菜单里的「个人资料」，补填学号后再提交。
- **Q: 提示需要先加入课程？**
  - A: 向任课老师或助教索取本学期邀请码，从账号菜单打开「加入课程」后即可提交正式作业。
- **Q: 题目显示「🌿 自主练习模式：本题目当前未作为任何选修课程的正式作业发布」？**
  - A: 说明老师尚未将该题目纳为当前班级的计分作业，此时该题目仅供自主代码练习，正式提交按钮会自动置灰。

## 在作业中使用 Notebook

打开课程作业后，点击“Notebook 视图”。作业代码单元会与代码视图同步，练习评分和正式提交使用同一份代码。其他单元用于测试和分析，不作为提交源码；请保留唯一带有 `submission` 标签的代码单元。点击“代码视图”可返回编辑器。考试期间使用代码视图。

首次使用会下载建模环境，支持直接导入 PySCIPOpt。正式成绩以服务端评测为准。
