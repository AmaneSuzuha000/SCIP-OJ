# 学生指南：SCIP-OJ 使用说明

欢迎使用 SCIP-OJ 系统建模与优化作业平台！本平台提供「**浏览器免配置本地自测与案例学习**」与「**网页端一键提交正式作业**」双轨功能。

当前站点只允许已授权的 GitHub 账号登录后进入。登录后进入「课程教学」，可以查看已加入的班级、课程作业、及格线、截止时间、草稿状态、提交记录与班级排行榜。

**浏览器里的运行一律只作练习，不计成绩。**

---

## 核心边界与要求（先读）

1. **正式成绩只认服务端评测**：在作答页点击「本地自测」或在「拓展学习」里运行 Notebook 都仅在你的浏览器本地执行，不会作为课程正式成绩；正式成绩必须点击「提交作业」，由服务端隔离容器判分入库。
2. **网页提交**：使用 GitHub 账号登录后，在班级作业工作台编写代码并提交，实时查看状态流转与 `F/C/I/O` 评测明细。
3. **学号绑定**：请务必在登录后核对并绑定你的**真实学号**与**姓名**，系统将自动对齐教师花名册并归档课程成绩；若作业开启了「严格禁贴 · 需核验」考试模式，需先由教师在花名册中人工核验你的身份后才可交卷。

## 模式一：课程作业作答与本地自测

1. **进入题目**：从顶栏进入「课程教学」，选择所在班级，在「课程作业」卡片上可直接看到题目编号与名称、及格分数线、私有实例组数、计分规则（如“截止前最高分”）、是否开启考试监测/严格禁贴，以及截止时间。点击卡片进入作答工作台。
2. **编写代码**：在工作台可切换「题目」与「代码」标签页，并在代码编辑器中实现 `solve(instance)` 函数：
   - 编辑器要求返回一个包含 `{"status": "optimal", "objective": float(...), "solution": ...}` 的字典（具体字段格式以当前题目说明和初始模板为准）；
   - 编辑器会自动在当前浏览器保存你的草稿，也可以点击「恢复模板」重置为初始模板。
3. **点击「本地自测」**：
   - 首次点击时按需下载浏览器内 Python 运行环境（Pyodide + SciPy/NumPy 约 29 MB 及课程 `pyscipopt` 兼容层），不影响网站首屏打开速度。
   - 在浏览器本地使用公开小规模教学样例校验函数签名、返回格式、可行性/守恒性质与样例最优性（结果仅作调试参考，与服务端私有随机实例独立）。
4. **点击「提交作业」与查看详情**：
   - 提交后右侧「正式评测状态」会自动跟踪评测队列进度（排队中 → 评测中 → 已完成），展示总分、`F/C/I/O` 分项得分与每组私有实例反馈。
   - 也可以在顶栏进入「提交记录」，点击单条记录的「详情」展开当时提交的只读源码和完整评测报告。
5. **系统异常保护**：若服务端 runner 或网络出现偶发基础设施故障，状态将显示为「系统异常，不计分」，**系统异常绝不会将你的成绩记为 0 分**，可联系教师批量/单条复判或稍后重提。
6. **网络要求**：首次按需加载本地 Python 环境、读取题面/选课、正式提交及查询成绩均需要网络连接。

## 模式二：拓展学习里的交互式建模案例

「拓展学习」里有 11 个交互式建模案例（`P001`、`P002` 及 `IE-OPT-03` 至 `IE-OPT-11`），全部直接嵌入课程单页应用中，在浏览器内运行，无需本地安装 Python、SCIP 或 Jupyter。

1. 打开「拓展学习」，点开任意一课（例如「IE-OPT-03 设施选址与产能分配」）。
2. 可以逐个点击单元旁的「运行」，或点击顶部「全部运行」按顺序执行所有代码单元并在下方查看输出；需要清理变量时可点击「重置环境」。
3. 代码单元可直接修改参数（例如更改固定成本、容量或目标权重）并重新运行，观察方案如何变化。

浏览器内运行的 `pyscipopt` 是课程提供的兼容层，底层由 Pyodide (CPython WebAssembly) + SciPy HiGHS 求解器驱动，支持课程案例使用的建模接口：

```python
from pyscipopt import Model, quicksum

model = Model("example")
x = model.addVar(vtype="B", name="x")
model.setObjective(x, "maximize")
model.optimize()
print(model.getObjVal())
```

**这一层只用于练习。**正式提交后会在服务端无网络隔离容器中用原生 PySCIPOpt 重新执行与判分，那份结果才是正式成绩。两者可行域一致，但求解器版本与参数不同，极端多解情况下具体选中的最优解向量可能不同（目标值一致）。

## 模式三：正式作业提交全流程

### 步骤 1：GitHub 账号登录
- 在访问页点击 **「使用 GitHub 登录」**，授权后返回主站，顶栏右上角账号菜单将显示你的姓名或登录名。

### 步骤 2：绑定学号与真实姓名
- 请打开右上角账号菜单中的 **「个人资料」**（未绑定学号的学生首次登录时也会看到引导）。
- 准确填写你的**学号**（如 `20260001`）与**真实姓名**（如 `李同学`）。若在花名册对齐后修改学号，原教师人工核验状态会自动失效，需等待教师重新核验。

### 步骤 3：输入课程邀请码选课
- 点击右上角账号菜单中的 **「加入课程」**。
- 输入任课教师发放的邀请码并确认加入；加入成功后系统会自动将你的账号与班级花名册中的预置记录对齐匹配。

### 步骤 4：考试防作弊模式说明
- 作业支持教师配置三种诚信策略：
  - **常规提交**：可正常编辑、粘贴代码与自测。
  - **考试监测**：编辑、粘贴与切屏计数会随提交附加给教师复核参考（不单独凭前端信号直接认定违规）。
  - **严格禁贴 · 需核验**：代码编辑器禁止粘贴操作，且服务端要求你已绑定学号并完成教师花名册核验后才允许提交。

## 常见问题与排错

- **Q: 提交时提示需要先绑定学号或未加入课程？**
  - A: 点击右上角账号菜单，分别检查「个人资料」（补填学号与真实姓名）和「加入课程」（输入本学期班级邀请码）。
- **Q: 提示需要教师核验身份后才允许提交？**
  - A: 说明当前作业启用了严格考试模式（`exam_block`），请联系任课教师或助教在「教师控制台 → 花名册与核验」中点击「核验确认」。
- **Q: 同题连续提交提示“需至少间隔 20 秒”或达到次数限制？**
  - A: 平台设有事务级提交节流（同题冷却 20 秒、每作业每小时限 12 次、每人每日限 60 次），请稍候再试，或先用「本地自测」充分调试后再正式提交。
