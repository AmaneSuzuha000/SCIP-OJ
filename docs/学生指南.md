# 学生指南：SCIP-OJ 使用说明

欢迎使用 SCIP-OJ 工业工程《系统建模与仿真》在线实验平台！本平台提供「**浏览器免配置本地练习**」与「**云端隔离评测正式提交**」两套互补体验，帮助你在课堂上专注于建模思路与结果分析。

**学习练习与正式成绩边界：** 在浏览器「拓展学习」与工作台「本地自测」中的运行结果仅作练习、不计成绩；课程正式成绩仅以点击「提交作业」后的云端评测结果为准。

---

## 开始前的三项准备

1. **登录平台**：使用已授权的 GitHub 账号登录课程网站；顶部右上角菜单会显示你的账号信息。
2. **绑定学号与真实姓名**：首次登录后，请打开右上角菜单中的 **「个人资料」**，准确填写学号与姓名。若后续更改学号，需要重新联系教师核对花名册。
3. **输入邀请码加入班级**：在右上角菜单点击 **「加入课程」**，输入任课教师提供的邀请码即可进入对应班级并查看课程作业。

---

## 课程作业与评测流程

### 1. 阅读题面与编写模型

从顶部进入「课程教学」，点击所在班级卡片即可浏览当前发布的作业（含及格线、考核模式、计分方式及截止时间）。进入作答工作台后：

- 在「题目」页面查看问题背景、数学约束说明与 `solve(instance)` 输入输出规范；
- 在「代码」编辑器中完成建模代码。浏览器会自动保存当前草稿，也可随时点击 **「恢复模板」** 还原初始代码骨架。

### 2. 本地样例自测（免配置调试）

点击工具栏的 **「本地自测」**，平台会在首次使用时自动准备浏览器内建 Python 建模环境。系统将使用一组公开小规模教学样例验证你的函数签名、输出格式、约束可行性以及样例目标值，帮助你快速排除语法和建模低级错误。

### 3. 正式提交与查看报告

确认代码无误后点击 **「提交作业」**：

- 右侧 **「正式评测状态」** 会实时跟随进度（排队中 → 评测中 → 已完成）；
- 评测结束后会展示总分、通过状态、分项维度明细（格式规范、约束满足、整数性与目标最优性）以及各组隐藏测试算例的反馈；
- 之后可随时在顶部 **「提交记录」** 中展开任意历史提交，查阅完整源码与详细报告。

> **异常保护说明**：若云端评测队列因网络或系统波动发生临时异常，页面会提示「系统异常，不计分」，绝不会将你的本次提交误计为 0 分。可稍候重提或联系教师协助复判。

## 交互式拓展建模案例

顶部「拓展学习」板块收录了 **11 套交互式 PySCIPOpt 建模案例**（涵盖 `P001`、`P002` 与 `IE-OPT-03` 至 `IE-OPT-11`），无需本地安装 Python、SCIP 或 Jupyter，打开网页即可动手实验：

1. 进入具体案例页面后，点击单个代码单元右上角的 **「运行」**，或点击顶部 **「全部运行」** 依次执行；
2. 欢迎直接改动单元中的成本、容量或惩罚权重并重跑，直观观察最优方案与各参数敏感性；需要清理临时变量时可点击 **「重置环境」**。

浏览器端使用面向教学的 `pyscipopt` 兼容接口完成求解，语法与课程主流建模写法保持一致：

```python
from pyscipopt import Model, quicksum

model = Model("example")
x = model.addVar(vtype="B", name="x")
model.setObjective(x, "maximize")
model.optimize()
print(model.getObjVal())
```

> 正式提交作业后，云端会在隔离环境中调用完整原生 PySCIPOpt 重新求解一组更大规模的独立算例。在存在多个同等最优解的问题上，浏览器与云端返回的决策变量方案可能有所差异，但最优目标值保持一致。

## 考试防作弊策略说明

教师在发布作业时可针对不同实验场景启用三种提交模式：

- **常规提交**：可自由编辑、粘贴代码与运行本地自测；
- **考试监测**：编辑、粘贴与切换窗口等操作频次将记录随提交供教师参考；
- **严格防作弊模式**：编辑器禁止粘贴操作，且需提前经任课教师在花名册中人工核验身份后方可正式交卷。

## 常见问题

- **Q：提交时提示未绑定学号或未加入课程？**
  - A：请点击右上角头像菜单，分别完善「个人资料」（学号与真实姓名）并在「加入课程」中输入班级邀请码。
- **Q：提示需要教师核验后才能交卷？**
  - A：当前作业开启了严格考试模式，请联系任课教师或助教完成花名册核验后再试。
- **Q：连续点击提交提示需要间隔等待？**
  - A：为避免重复并发提交占用排队资源，同一题目连续提交之间需至少间隔 **20 秒**，同时建议每次修改后先通过「本地自测」确认再正式交卷。
