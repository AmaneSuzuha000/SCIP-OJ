# 学生指南：SCIP-OJ 使用说明

欢迎使用 SCIP-OJ 工业工程《系统建模与仿真》在线实验平台！本平台提供「**浏览器免配置本地练习**」与「**云端隔离评测正式提交**」两套互补体验，帮助你在课堂上专注于建模思路与结果分析。

> **学习练习与正式成绩边界**：在浏览器「拓展学习」与作答工作台「本地自测」中的运行结果仅作练习，**不计成绩**；课程正式成绩仅以点击「提交作业」并完成云端容器评测后的结果为准。

---

## 开始前的三项准备

| 步骤 | 操作说明 | 入口位置 |
| --- | --- | --- |
| **1. 登录平台** | 使用已纳入课程授权名单的 GitHub 账号登录 | 页面右上角「登录」按钮 |
| **2. 绑定学号与姓名** | 准确填写个人学号与真实姓名，供成绩归档与花名册对齐 | 右上角头像菜单 → **「个人资料」** |
| **3. 加入授课班级** | 输入任课教师提供的班级邀请码即可查看对应作业与排行榜 | 右上角头像菜单 → **「加入课程」** |

> 若后续在「个人资料」中修改学号，原班级的线下核验状态会自动失效，需要重新联系任课教师核对。

## 课程作业与评测流程

### 1. 阅读题面与编写模型

从顶部进入 **「课程教学」**，点击所在班级卡片即可浏览当前发布的作业（含及格线、考核模式、计分策略、测试算例组数及截止时间）。进入作答工作台后：

- 顶部工具栏支持在 **「题目」**、**「代码」** 与桌面端 **「分屏对照」** 三种视图间切换；
- 题面内提供完整的数学规划模型（MILP）、`solve(instance)` 接口表、公开自测样例与常见失分排查表；
- 代码编辑器自动将草稿缓存在当前浏览器中，也可随时点击 **「恢复模板」** 还原初始代码骨架。

### 2. 本地样例自测（免配置调试）

点击工具栏的 **「本地自测」**，平台会在首次使用时按需加载浏览器内建 Python 建模环境。系统将使用题面第 4 节列出的公开小规模样例验证你的函数签名、输出格式、约束可行性以及样例最优目标值，帮助你快速排除语法和建模低级错误。

### 3. 正式提交与查看报告

确认代码无误后点击 **「提交作业」**：

- 右侧 **「正式评测状态」** 会实时跟随进度（排队中 → 评测中 → 已完成），重返或刷新工作台页面也会自动恢复最近一次提交的评测结果；
- 评测结束后会展示总分、通过状态、**四维分项得分进度（格式 `F`、约束 `C`、整数性 `I`、目标 `O`）** 以及各组隐藏测试算例的反馈明细；
- 之后可随时在顶部 **「提交记录」** 按状态筛选并展开任意历史提交，支持一键复制源码并查看完整评测报告；也可在班级详情页的 **「课程排行榜」** 按「综合」或具体题目切换排名（学号已作脱敏处理）。

> **异常保护说明**：若云端评测队列因网络或系统波动发生临时异常，页面会提示「系统异常，不计分」，绝不会将你的本次提交误计为 0 分。可稍候重提或联系教师协助复判。

## 交互式拓展建模案例

顶部 **「拓展学习」** 板块收录了 **11 套交互式 PySCIPOpt 建模案例**（涵盖 `P001`、`P002` 与 `IE-OPT-03` 至 `IE-OPT-11`），支持按「正式同款 / 专题拓展」分类筛选与关键词检索，无需本地安装 Python 或求解器即可动手实验：

1. 进入具体案例页面后，点击单个代码单元右上角的 **「运行」**，或点击顶部 **「全部运行」** 依次执行；
2. 欢迎直接改动单元中的成本、容量或惩罚权重并重跑，直观观察最优方案与各参数敏感性；需要清理临时变量时可点击 **「重置环境」**。

浏览器端使用面向教学的 `pyscipopt` 兼容接口完成求解，语法与课程主流建模写法保持一致：

```python
from pyscipopt import Model, quicksum

model = Model("example")
x = model.addVar(vtype="B", name="x")
model.setObjective(x, "maximize")
model.optimize()
print(model.getObjVal())
```

> 正式提交作业后，云端会在隔离环境中调用完整原生 PySCIPOpt 重新求解一组更大规模的独立算例。在存在多个同等最优解的问题上，浏览器与云端返回的决策变量方案可能有所差异，但最优目标值保持一致。

## 考试防作弊策略说明

教师在发布作业时可针对不同实验场景启用三种提交模式：

- **常规提交**：可自由编辑、粘贴代码与运行本地自测；
- **考试监测**：编辑器记录编辑、粘贴与切换窗口等操作频次，随提交保存供教师在复核弹窗中参考（不单独作为违纪判定依据）；
- **严格禁贴（需核验）**：编辑器禁止粘贴操作，且须提前经任课教师或助教在花名册中完成线下身份核验后方可正式交卷。

## 常见问题

- **Q：提交时提示未绑定学号或未加入课程？**
  - A：请点击右上角头像菜单，分别完善 **「个人资料」**（学号与真实姓名）并在 **「加入课程」** 中输入班级邀请码。
- **Q：提示需要教师核验后才能交卷？**
  - A：当前作业开启了严格考试模式，请联系任课教师或助教在「教师控制台 → 花名册与核验」中核对后重试。
- **Q：连续点击提交提示需要间隔等待？**
  - A：为避免重复并发提交占用排队资源，同一题目连续提交之间需至少间隔 **20 秒**，同时建议每次修改后先通过 **「本地自测」** 确认再正式交卷。
