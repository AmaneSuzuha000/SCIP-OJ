## 6. 优化落地最终方案

### 6.1 一周内（开课最小闭环）

1. **跑通 Release Gate（#14）**  
   - 验收标准：隔离课程下，真实学生账号提交 1 题 → Actions 沙箱成功 → 成绩表出现 effectiveGrade → 教师复判产生新 attempt 且旧 effective 策略符合合同。  
   - 产出：Issue #14 评论贴时间线 + workflow run URL。
2. **Owner 处理 #15**（supabase_admin 默认权限）。  
   - 验收：对新表/新函数抽查 `has_table_privilege` / default privileges 合约测试仍绿。
3. **关闭或改写 #20**，避免团队按过时 P0 施工。
4. **合并并 push 本报告对应的 P1 修复**（course 表格视图 + assignments escape）——需你一句确认后再推。
5. 确认 `recover-gradings` schedule 在 GitHub Actions 对 main 启用且近 24h 有成功 run（可为空队列）。

工作量估计：0.5–1.5 人日（含你配合 OAuth 账号）。

### 6.2 一个月内（课堂可撑住）

1. 并发压测：同作业突发 N 提交（建议 N=20→50），观察 queue→lease→callback、system_error 重试≤2。  
2. 成绩表大数据量 UX（虚拟滚动或分页，若 roster×problems > 阈值）。  
3. 镜像 digest / runner 版本写入证据页或 `config_snapshot` 扩展字段。  
4. 相似度报告只读入口挂到教师证据台（先只读）。  
5. CI 固定 Playwright teacher smoke（修复本机缺口）。

工作量估计：3–6 人日。

### 6.3 学期内（内容与演进）

1. Issue #21：IE-DES-01 升级为完整可评分实验（保持私有实例隔离合同）。  
2. 考试花名册核验运营剧本固化（导入→匹配→核验→开考）。  
3. 可选：Vite/TS 渐进；**不阻塞开课**。  
4. 若并行调研工具就绪（`/parallel-setup`），补一版「同类 OJ 判题隔离/合同」对照附录。

工作量估计：按课程内容排期，平台侧 2–4 人日可穿插。
