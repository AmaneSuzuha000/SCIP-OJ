# 工业工程《系统建模与仿真》精品案例 · 学生实验与教师评价规范 v1.1

> 范围：IE-DES-01（工位排队）、IE-MC-02（随机库存）、IE-DES-03（双工序流水线），以及现有 PySCIPOpt 背包/指派入门题。下面是建议的课程评分量表，**没有与线上 正式评测 正式成绩系统连接**。教师采用前须明确课程政策、分数版本与申诉安排。

## 一、通用交付物

每组提交 1 份实验报告、1 份可执行模型/代码、1 份原始实验数据及运行参数。图表必须标注指标单位、随机种子、观测长度、预热长度、重复次数、事件/需求模型和软件版本。

| 维度 | 分值 | 最低可核验证据 | 典型扣分风险 |
|---|---:|---|---|
| 业务问题与系统边界 | 15 | 目标、资源、实体、事件、范围和不可模拟内容 | 把模拟假设表述成实际工厂事实 |
| 数学模型与事件逻辑 | 20 | 状态更新顺序、守恒或约束检查、核心算法 | 未定义到达/完成/资源释放时点 |
| 独立验证 | 20 | 至少两种边界测试、一个理论/手算或独立实现对照 | 只说“程序运行成功” |
| 实验设计与统计 | 20 | A/B 同分布配对、固定 seed、独立重复、区间和反例 | 将有限时域结果冒充稳态；挑种子 |
| 工程分析与决策 | 15 | 效率—成本权衡、方案取舍和局限性 | 只报最优值不解释适用范围 |
| 复现与表达 | 10 | 代码、参数、版本、CSV、清晰图表与引用 | 无法复算、单位缺失、来源不明 |
| **合计** | **100** | | |

**建议硬门槛**：核心逻辑不可重复、编造运行数据、伪造实测来源、使用未知外部数据却不披露等情形，应先进入人工核验，不以客户端自报数值直接赋正式分。课程诚信认定须依据学校规定和人工程序，不能仅凭浏览器禁粘贴。

## 二、三套可直接开课的案例教案（每个案例 1～2 学时，进阶报告课后完成）

### IE-DES-01 检修工位排队

- 教学重点：实体/资源/事件；Poisson 到达、指数服务、FCFS；排队等待、利用率、WIP；共同随机数及配对 CI。
- 课堂动作：固定 lambda=1/8 件/分钟、平均工时 12 分钟，比较 2 与 3 个工位，重复次数 5→30→100。
- 必要验证：同策略差值必须严格为 0；低负荷时等待应下降；稳态 M/M/c 的 Erlang-C 等待公式对照**仅在 rho<1、长观察期近似成立**。
- 核心问题：如果增加工位的固定成本未知，为什么“等待下降”还不能直接得出最优工位数？

### IE-MC-02 随机库存

- 教学重点：独立 Poisson 日需求、定期检查 (R,S) order-up-to、确定性提前期、lost-sales、成本与服务水平权衡。
- 课堂动作：改变 S=8/14、提前期 2→5 天和缺货成本 9→30 元；比较平均成本、填补率、缺货天数。
- 必要验证：每日供需守恒 demand=served+lost，零需求且正库存时无订单、只发生持有成本；一天补货提前期+每天恒定需求下可手算。
- **边界**：未计单位采购费、回溯补发、季节性、多供应商与供应中断，不能直接映射到真实 ERP 成本。

### IE-DES-03 双工序生产线

- 教学重点：串行 DES、blocking-after-service、有限缓冲、工序饥饿/阻塞、产量—WIP 权衡。
- 课堂动作：方案 A=0 缓冲，B=1/3/6 缓冲；改变第二工序时间以检验瓶颈迁移。
- 必要验证：入线任务总数−累计完工数=系统内任务数；工序二“加工占比+空闲占比≈1”；极简三任务实例下扩展缓冲应使一工序阻塞下降。
- **边界**：两台串联设备、无限外部等候、FCFS；没有故障、返工、并行设备或运输资源，不应自称真实数字孪生。

## 三、优化模型与仿真衔接任务（对齐官方 Examples）

1. 先阅读 PySCIPOpt 官方 mkp.py、eoq_en.py、flp.py、pfs.py 的模型结构，标记变量、约束、目标与假设（主入口见 [官方例题导航](../site/official-examples.html)）。
2. 任选库存或生产线场景，解释确定性优化与随机仿真的输入数据/评价指标有何区别；**官方原码的输出不是本站仿真案例的标准答案**。
3. 不声称求解器最优就意味着动态工况下执行最优；需要给出独立可行性检查、参数扰动和统计比较。
4. 引用官方来源时标明访问日期、源码文件、版本/commit；第三方代码分发须遵守各自版权和许可证。

## 四、教师准备清单

- [ ] 确认三种模型假设与授课节次匹配
- [ ] 先跑零需求/恒定需求/三任务阻塞/同方案配对零差值等边界测试
- [ ] 固定课程 seed、实验时域与参数范围，并登记版本
- [ ] 如需正式评分，先通过真实学生和教师账号的权限/存档/复判/申诉 E2E
- [ ] 在课程说明中区分**课堂本地仿真 CSV**与**正式评测 正式成绩表**
- [ ] 教师对不稳定统计区间或异常结果进行人工复核
- [ ] 课程试运行后记录前测、后测、主观负荷、完成率和常见误区

## 五、统计与复现约定

三例为浏览器本地教学模拟，不上传学生数据；重复数可配置 5～100。配对置信区间使用样本标准差和 1.96 的正态近似，不保证小样本覆盖。应检查种子敏感性、多个场景、观察时域、预热与外部有效性，不能把区间跨零误读为“无任何差异”。除非另有明确记录，本案例产生的数值全部为**教学合成数据**，不是厂内真实绩效。

## 六、独立 SCIP 建模课程（对应网页官方 Examples）

目前另有四套独立实现的 PySCIPOpt Notebook：IE-OPT-03 容量约束设施选址、IE-OPT-04 仓储装箱、IE-OPT-05 排列流水车间、IE-OPT-06 单周期随机库存优化。分别使用 81 种客户分配枚举、递归装箱、24 种排程序列枚举、全部整数订货量枚举验证小算例最优解。可用于约束建模/优化与仿真衔接教学，但**未接入 正式评测 权威成绩**。

课程评价应要求学生分辨四个模型各自的最优性证明范围、合成数据来源与仿真案例的额外随机假设；不能把这些小模型的最优性用于宣称复杂动态车间的全局最优。
