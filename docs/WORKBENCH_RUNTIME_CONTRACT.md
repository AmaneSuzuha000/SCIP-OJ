# 运行与作业契约

## 边界

- 门户：题目、班级作业、草稿、正式提交与成绩展示。
- 浏览器建模：唯一 xeus-python / PySCIPOpt 环境，代码视图和 Notebook 视图共用运行适配器；不再提供能力不同的 Pyodide 分支。
- 课程服务：认证、作业权限、正式评测、成绩与教师记录；不接受浏览器评分作为正式成绩。
- 开放案例：独立拓展学习资源，保持与课程成绩分离。

## 源码与状态

正式提交、重试、可信评分及有效成绩的合同见 [正式提交与成绩契约](GRADING_CONTRACT.md)。浏览器练习不进入正式成绩链路。

作业源码依然是 `solve(instance) -> dict`。代码编辑器是提交源码的当前表示；作业内 Notebook 唯一带 `submission` 标签的单元同步该表示并触发相同的草稿保存路径。测试、绘图等其他单元不进入提交源码。删除或重复作业单元时，运行和提交被阻止。考试模式禁止切换 Notebook；服务端考试策略不依赖此 UI 限制。

每次练习使用独立内核和新 Python globals，输出必须可序列化为 JSON。运行超时销毁承载内核的 iframe；恢复后重新启动，不回退到另一种不支持 SCIP 的运行时。作业源码保存在门户草稿中；Notebook 的其他实验单元仍属于浏览器 Notebook 存储，不承诺跨设备同步。

## 构建

`content/` → JupyterLite build → `lite-build/`。

`site/` + `docs/` + `problems/` + `lite-build/` → `scripts/assemble_site.py` → `dist/`。

生成运行环境保持完整地放在 `dist/notebooks/`。门户根页无需包含 JupyterLite 的配置脚本；不再先覆盖后修补。根目录 `docs/` 为文档唯一来源。旧 Lab/REPL 地址将 Notebook 文件参数映射到门户工作台的规范路由。显式维持既有内容存储名称，不主动删除学生的浏览器文件。

## 验证

单元测试检查资源边界、唯一文档来源、失败不覆盖目录、运行协议、超时销毁与恢复。Chromium 集成测试构建完整 JupyterLite，实际执行 PySCIPOpt 背包求解、Notebook 源码同步与草稿保存、超时与恢复。既有判题、权限、考试与仿真回归继续运行。浏览器与服务端 Python 包版本可能不同，因此最终成绩仍独立判定。

## Notebook 会话归属

每次打开使用独立请求标识。离开视图、切换题目或运行环境重置会使旧请求失效；异步文件读取、保存和组件创建结束后都再次核对归属。文件操作串行执行，避免旧保存覆盖新打开。同一道题重新进入也会产生新视图标识，旧回调不能修改当前源码、状态或按钮。Jupyter 对象访问位于 iframe 内的引擎，门户适配器不访问这些对象。

## 门户与运行环境通信

门户适配器只持有 iframe、版本化 MessageChannel、请求编号和已同步的源码缓存。Jupyter 模型与服务访问集中在 `notebook/engine.js`，由 `notebook/bridge.js` 提供 ready/prepare/run/open/study/detach 白名单接口。握手检查父窗口和同源，源码事件绑定打开请求，重置关闭端口并拒绝待处理请求。构建组装器只在生成的 Lab 页面载入这两个文件，不修改 JupyterLab 发行包，也没有实现预编译 Jupyter 扩展。运行环境依然独立构建，真实浏览器测试继续验证实际 SCIP 求解与 Notebook 单元同步。

页面进入即通过 `prepare` 命令完成 Python / PySCIPOpt 检测和微型 SCIP 求解；同一准备请求合并，内核等待 `kernel.info`，检测上限为 120 秒。只有完成检测的备用内核可用于测试，使用后销毁并补充下一份。准备状态在页头显示，不写入测试报告；代码执行才开始计算题目时限，执行进度通过同一请求编号的 `progress` 消息回传。停止运行销毁 iframe 并保留门户草稿；切题、返回题单使旧运行及进度失效。练习评分与自定义测试共享执行锁，题目加载完成、事件绑定后才启用按钮。

浏览器评分器按题目类型显式注册；IE-DES-01 使用公开仿真参数与独立参考仿真，不再回落为背包题。`test_ie_des_practice.mjs` 将正常和异常输出与服务端 Python 评分器逐项核对。`test_practice_browser.cjs` 验证按钮进度、停止重试和旧结果隔离，完整运行环境测试通过实际点击「运行此测试」执行 PySCIPOpt。

## 导航归属

公共页面由同一页头组件构建。可见入口只有课程教学、拓展学习两个空间；教师管理属于课程教学。原始教学与拓展 Notebook 通过 `study` 命令在同一工作台中打开，不进入正式提交或源码同步链路。路由目录明确每份 Notebook 的空间与返回地址，旧 Lab/REPL 仅作兼容。工作台位于共享容器，运行 iframe 在切换视图时不移动或重建。
