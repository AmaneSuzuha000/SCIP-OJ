# 第 1 课 · 建模与 SCIP 入门

返回 [课程学习路径](doc.html?path=docs/课程学习路径.md)。

## 学习目标

- 能把一个决策写成变量、约束和目标，并说清哪些量是数据、哪些量是要求解的。
- 能区分线性规划、整数规划和混合整数规划。
- 能说明分支定界为什么不必把所有整数点都试一遍。
- 能用 PySCIPOpt 跑通背包和指派两个小模型。

## 一个模型里有什么

优化模型回答三件事。

**决策变量**是可以选的量。背包里某件物品拿或不拿，是 0 或 1。运输问题里某条线路发多少箱，是非负的数量。变量的类型要跟业务一致：不能把「开不开一家仓库」写成任意实数。

**约束**是必须遵守的关系。背包的总重量不能超过容量；指派里每个人恰好做一件事、每件事恰好有一个人。约束写漏了，求解器会给出一个数学上最优、业务上做不到的方案。

**目标**是要推动的方向，而且一次只能有一个优化方向。最小化总费用，或最大化总价值。如果同时在意费用和服务时间，需要先说清是加权成一个目标，还是把其中一个改成约束。

数据（容量、费用、需求）在求解前是已知数，不要和变量混在一起。改数据会改最优方案；改变量的含义则是另一个模型。

## 线性规划、整数规划、混合整数规划

线性规划里，变量在区间上连续取值，目标和约束都是这些变量的线性式。运输问题常常属于这一类：发货量可以按比例理解，约束是供需平衡。

整数规划要求部分或全部变量取整数。0-1 变量是整数变量的特例，用来表示「选或不选」「走或不走」。背包和指派都是 0-1 规划。

混合整数规划里，整数变量和连续变量同时存在。例如「仓库开不开」是 0-1，「开了之后送多少货」是连续或整数数量。设施选址 Notebook 就是这种结构。

线性规划的可行域是凸的，顶点里就有最优解。加上整数要求之后，可行点变成离散的，一般不能再靠只解一次线性规划收场。

## 分支定界在做什么

对最小化问题，分支定界可以这样理解。

先丢掉整数要求，解一个线性规划松弛。松弛允许原来不合法的分数解，所以它的最优值不会比真正的整数最优值更差：它是一个下界。如果这个松弛解碰巧已经是整数，它就是原问题的最优解。

如果某个变量取了分数，就把它拆成两支。一支要求这个变量不大于当前的整数部分，另一支要求它不小于下一个整数。两支各自再解松弛。

手上一旦有一个可行的整数解，就有了上界。某一支的松弛下界已经差于这个上界，整支都可以丢掉，因为里面不可能再出现更好的整数解。

SCIP 负责分支、剪枝、割平面和搜索策略。PySCIPOpt 是建模接口：你声明变量、约束和目标，调用 `optimize()`，再读状态和取值。状态不是 `optimal` 时，当前目标不能当作最优值。

本课不实现分支规则。要建立的习惯是：先写对模型，再把求解器当成黑箱，并用一个小例子的独立枚举核对它。

## 自测

下面几题没有标准答案。能向同学讲清楚即可。

1. 把「最多选 3 个项目」写成约束。如果写成目标里的一项，模型和原来的问题还相同吗？
2. 松弛解的目标值是 40，你另外找到一个可行整数解，目标值是 46。对最小化问题，最优值落在哪个范围？哪一类分支可以被剪掉？
3. 求解器返回的状态不是 `optimal`。页面上仍有一个目标数字。这个数字可以写进实验结论吗？
