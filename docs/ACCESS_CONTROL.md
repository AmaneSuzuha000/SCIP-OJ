# 平台访问控制与发布边界说明

本说明约定平台部署过程中的公开边界与静态构建产物规范，供课程维护与部署参考。

## 权限边界原则

1. **静态页面与公开教学资料**：单页应用前端代码、课程公开指南文档、拓展交互式 Notebook 案例及浏览器端求解运行时属于公开静态资源，不包含任何隐藏测试用例答案或敏感配置。
2. **业务数据与接口访问**：课程班级、作业提交、花名册、成绩簿与教师管理接口全部实施严格的服务端鉴权（OAuth 身份校验 + 行级数据访问控制），仅授权用户在本人权限范围内读写数据。
3. **前端与后端职责分离**：前端界面权限控制仅作交互引导，不作为安全边界；所有身份核验、限流与角色鉴权均由后端数据层与无状态服务接口强制执行。

## 静态产物发布检查

`scripts/assemble_site.py` 是站点静态打包的统一出口，负责保证：

- 仅包含 `web/dist` 应用产物、前端 Pyodide 运行时以及经过审核的公开教学文档；
- 仓库内的题目参考答案、私有评测代码、内部说明与工程配置严禁进入静态站输出目录；
- 输出目录通过自动化回归测试持续校验（见 `tests/test_assemble_web.py`）。
