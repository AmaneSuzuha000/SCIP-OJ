# 课程学习路径

这条路径把建模概念、交互式案例与 OJ 正式作业按学习顺序串起来。可以按三课顺序阅读，也可以直接点开任意一课的交互式 Notebook 动手修改参数。

访问站点前，需要使用已获授权的 GitHub 账号登录。访问白名单只控制站点入口权限，不改变作业计分规则。浏览器里的拓展案例和「本地自测」用来验证建模与边界逻辑，**不计入正式成绩**；正式成绩只来自「课程教学」中「提交作业」后的服务端隔离评测。

## 建议节奏

| 模块 | 在学什么 | 建议学时 | 从这里进入 |
| --- | --- | --- | --- |
| 第 1 课 建模与 SCIP | 变量、约束、目标；线性规划与整数规划；分支定界剪枝思想 | 2 学时，外加在工作台通过 P001 | 拓展学习 · P001 / 课程教学 |
| 第 2 课 经典组合优化 | 运输、下料、装箱、指派、设施选址与随机库存规划 | 3 学时 | 拓展学习 · P002 与 IE-OPT-03 至 IE-OPT-08 |
| 第 3 课 路径与调度进阶 | 巡检回路（MTZ）、带容量配送（CVRP）与单机总延误调度 | 3 学时 | 拓展学习 · IE-OPT-09 至 IE-OPT-11 |

学时对应课堂阅读与至少一次改参实验，而不是单纯浏览。某一课理解卡住时，可直接在代码单元修改成本、容量或目标权重，使用「运行」观察方案变化，并用「重置环境」清理状态。

## 练习与正式提交

- **浏览器练习**：拓展学习里的 11 个案例以及作业工作台的「本地自测」均在浏览器 Pyodide 中执行，结果不进入课程成绩簿。
- **正式提交**：登录并输入邀请码加入班级后，从「课程教学」进入教师发布的作业点击「提交作业」。当前服务端 L2 隔离容器已支持 `P001`（0-1 背包）与 `P002`（指派优化）；`IE-OPT-03` 至 `IE-OPT-11` 仅作拓展练习，不会自动写入成绩簿。
- 教师发布作业后，作业卡片与工作台顶部会直接显示该作业的及格分数线、私有实例数量、计分规则与截止时间。

## 可以直接使用的材料

- 拓展学习：11 个 PySCIPOpt 交互式案例，支持单格执行、全部运行与环境重置。
- 正式判题题库：`P001` 0-1 背包、`P002` 指派优化。
- 完整操作步骤见 [学生指南](/docs/student-guide)，实验评价细则见 [课程实验与评价规范](/docs/grading-rules)。

## 这一轮先不展开

以下三个扩展方向只在课程阅读中介绍概念与数学结构，本轮未单设独立案例或 OJ 题：

- **广义指派**：一台机器或工人可承担多项有容量约束的任务；普通指派是单位容量特例。
- **带时间窗的车辆路径（VRPTW）**：在带容量配送模型基础上进一步要求访问时刻落在给定时间窗内。
- **并行机调度**：多台平行机器协同加工，决策同时包含指派与机上排序。
