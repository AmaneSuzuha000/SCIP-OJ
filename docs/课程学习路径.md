# 课程学习路径

本学习路径将优化建模概念、浏览器交互式案例与线上正式实验串联在一起。建议按阶段循序阅读并结合代码单元进行改参实验，加深对模型结构与边界条件的理解。

登录后即可从「课程教学」进入所属班级提交正式作业；「拓展学习」与工作台「本地自测」用于在浏览器中探索和检验思路，**均不计入正式成绩**。正式成绩以在班级作业中点击「提交作业」并完成云端评测后的结果为准。

---

## 三阶段学习路线

| 学习阶段 | 核心建模能力 | 建议学时 | 对应入口 |
| --- | --- | :---: | --- |
| **第 1 课：建模基础与 SCIP 入门** | 理解决策变量、线性约束、目标函数方向及 `Model`/`quicksum` 基本 API | 2 学时 + `P001` | 拓展学习 · `P001` / 课程教学 |
| **第 2 课：经典组合与资源优化** | 掌握平衡指派、设施选址、一维装箱、流水调度、平衡运输、下料与随机库存建模 | 3 学时 | 拓展学习 · `P002` 与 `IE-OPT-03` 至 `IE-OPT-08` |
| **第 3 课：路径规划与调度进阶** | 理解 MTZ 破圈约束、带容量配送（CVRP）与基于位置顺位的单机总延误调度 | 3 学时 | 拓展学习 · `IE-OPT-09` 至 `IE-OPT-11` |

> **实验建议**：每节课建议完整执行至少一次代码单元，并尝试调整成本系数、容量上限、惩罚权重或需求概率，对比优化前后决策结构与约束紧度，而非仅作静态阅读。

## 练习环境与线上考核说明

- **线上正式考核题目**：目前系统开放 `P001`（0-1 背包优化）与 `P002`（平衡指派优化）线上编程作业；进入班级后在作业卡片即可查看及格线、测试算例组数、计分规则、考核模式与截止时间。
- **拓展学习案例**：`IE-OPT-03` 至 `IE-OPT-11` 均为独立交互式实验材料，在浏览器内即可运行并附带独立穷举或动态规划参照校验，不单独写入班级成绩单。
- **延伸手册**：详细的操作步骤请参阅 [学生指南](/docs/student-guide)，四维分项细则与开放实验评价标准请参阅 [课程实验与评价规范](/docs/grading-rules)。

## 延伸进阶主题

以下方向在课堂中作为概念拓展介绍，供学有余力的同学在掌握基础模型后进一步思考建模思路：

- **广义指派问题（GAP）**：在平衡指派的基础上引入资源容量约束，允许单台设备承接多项任务，适合建模多任务负载平衡与异构资源分配；
- **带时间窗的车辆路径问题（VRPTW）**：在带容量配送模型中增加客户服务时间窗口与到达时刻递推约束；
- **并行机调度与阻塞流水线**：多台设备协同加工任务时，需同时决策「任务分配到哪台设备」与「各设备上的加工排序」，或进一步结合离散事件仿真验证有限缓冲区阻塞现象。
