# IE-DES-01 精品案例实验指导书：检修工位排队与离散事件仿真

课程：工业工程《系统建模与仿真》，建议 2 学时课堂 + 课后报告。

**课程边界**：合成教学数据；本地实验与独立复算不等于正式 OJ L2 评分，也不代表真实车辆段运营绩效。

## 1. 原始决策问题

在到达需求与检修工时不变时，增加工位能否用排队收益抵偿工位固定成本？每组学生最终提交：问题建模、事件流程、三任务手算验证、可复算的成组仿真证据、置信区间与成本敏感性分析。

### 模型合同

- 实体：排队的单件检修任务；资源：c 个同质平行工位；先到先服务 FCFS。
- 随机到达间隔独立 Exp(mean=8 min)，服务工时独立 Exp(mean=12 min)；空系统启动，无限等候区，无抢占。
- 方案 A 为 2 工位，B 为 3 工位；方案之间唯一操作差异应是工位数。
- 默认仿真 [0,480) min，预热时点 60 min，30 次独立重复；每一重复 A/B 共享同一到达与工时列表（common random numbers）。
- 等待时间属于观察窗口内**到达**的任务 cohort，可允许开工时间超过 horizon。时间平均队列、WIP、占用率与完成件数仅统计 [warmup,horizon] 窗口，不能无条件套用稳态 Little 定律。
- 不包括 AGV、吊运、跨线共享工人、返工、作业优先级、有限等候空间与死锁，不能据此推出真实检修产能结论。

理论负荷率：

\[
\rho_c=\frac{\text{serviceMean}}{\text{arrivalMean}\cdot c}.
\]

默认参数下，A 为 0.75、B 为 0.50。只有理想 M/M/c 系统理论上的 \(\rho<1\) 才有有限稳态平均等待；短时模拟即使负荷超载仍可产生有限观测值，不能解释为稳态。

## 2. 每个学生都应完成的三任务手算

给定到达时点 0、0.5、1 分钟，服务工时 2、2、1 分钟：

| 任务 | 到达 | 单工位开工、完工、等待 | 双工位开工、完工、等待 |
|---|---:|---|---|
| J1 | 0 | 0、2、0 | 0、2、0 |
| J2 | 0.5 | 2、4、1.5 | 0.5、2.5、0 |
| J3 | 1 | 4、5、3 | 2、3、1 |

推导结果：

- 单工位平均等待 = 1.5 min，双工位平均等待 = 1/3 min。
- 观察窗口 [0,6] 中，两方案总加工时间都为 5 min。
- 利用率为 5/6 与 5/12；平均队列长度为 0.75 与 1/6。
- 该确定性微型例子用于**事件逻辑手算**，不要求与网页的随机实例数值相等。

## 3. 90 分钟课堂执行单

| 时间 | 内容 | 提交证据 |

| 50–65 分 | 对比 5/30/100 次重复、两个不同种子 | 全部原始结果、种子敏感性 |

| 80–90 分 | 加入工位成本，提出保留条件 | 有条件的工程建议 |

每次改参数后应重新运行再导出证据，禁止只挑最有利的一次。

## 4. 教师独立复算

将浏览器的 IE-DES-01-verifiable-experiment.json 与项目源码放在可访问的位置，在仓库根目录运行：

    python -m judge.ie_des01_reference IE-DES-01-verifiable-experiment.json

验证成功时状态为 VERIFIED_REPLAY。验证器独立重建 32 位随机流，用完成时间小根堆重新执行 FCFS；逐重复比较等待、完成数、队长、WIP、占用率及汇总的 B−A 区间。可使用以下回归：

    python -m unittest discover -s tests -p 'test_ie_des01_reference.py' -v
    node tests/test_simulation_core.cjs

**重要**：重放只能证明数值与公开模型一致，不能证明学生身份、原创性、解释是否正确或实测来源。JSON 是学生本地可编辑证据，不是加密签名或正式成绩记录。

## 5. 将时间收益变成工程决策

设工位固定成本 C（元/工位小时）、等待损失 P（元/件分钟）、期望到达率 \(\lambda_h=60/\text{arrivalMean}\)（件/小时），定义本案例的粗略小时目标：

\[
J(c)=cC + P\lambda_h E[W_q(c)].
\]

用平均等待点估计，增加一个工位的盈亏临界条件：

\[
C < P\lambda_h(\widehat W_{q,2}-\widehat W_{q,3}).
\]

应使用配对置信区间给出临界阈值的不确定范围。实际工厂还需预算、班次、工人、搬运、前后工序及安全约束才能做投资决定。
