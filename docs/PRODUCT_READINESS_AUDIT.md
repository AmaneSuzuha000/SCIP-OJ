# 面向师生的产品化审计

本次审计检查项目页面、学生与教师流程、当前指南、首页文档入口、案例目录及运行失败反馈。视觉样式沿用已回退确认的版本。

| 发现 | 处理 |
| --- | --- |
| L1/L2 暴露实现分层 | 页面、提示、当前指南统一使用“练习评分 / 正式提交 / 正式评测”；浏览器评分报告显示“练习” |
| 运行环境失败后给出内置示例成绩 | 删除该页面路径；未执行学生代码时直接报错，不生成示例成绩或练习通过记录 |
| 课程案例混入未实现规划 | 移除三个规划占位，保留三个可运行案例与原有卡片样式 |
| 用户提示包含部署变量和配置文件排障 | 改为服务不可用及重试提示；后台日志与维护配置继续保留 |
| 学生指南保留 PR/Actions 迁移说明和阶段编号 | 改为当前网页操作流程；修正首次加载和离线能力的过度承诺 |
| 教师指南暴露数据库授权和签名回调细节 | 改为管理员授权、源码审查与结果保存的教学语言 |
| 使用文档导航包含仓库 README | 移除师生文档导航中的仓库入口；仓库仍保留 README |
| README 混杂阶段升级指南与未来规划 | 当前功能置前，历史记录归入维护说明 |

保留事项：练习不计入正式成绩的区别、实验数据来源、评分规则、版权说明、考试操作限制和故障提示均属于必要产品信息。源码函数名、数据库契约、判题隔离、迁移文件、测试、历史审计与版本记录用于系统维护，不因展示清理而删除或盲目改名。

本次不是对所有安全性质的重新证明。判题、权限、隔离和仿真算法继续由现有回归验证；未操作真实师生数据。
