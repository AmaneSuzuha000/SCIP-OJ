## 使用小贴士

- **即开即用**：点击任意代码单元的 **「运行」** 或页面顶部的 **「全部运行」**，首次触发时会自动加载浏览器端 Python 运行环境；代码单元共享同一个上下文命名空间，可随时点击 **「重置环境」** 清空变量还原。
- **独立结果核验**：每个拓展案例均内置小规模枚举或动态规划对照算例，方便你在修改模型公式后立即验证约束与目标是否建模正确。
- **教学数据说明**：案例所使用的需求量、工时、距离与成本矩阵均为 **合成教学数据**，仅用于课程规律演示；迁移至实际工业分析时应补充真实假设与数据校准。
- **学习衔接**：各专题的推荐学习顺序与延伸方向请见 [课程学习路径](/docs/learning-path)。
