# 拓展学习指南

拓展学习板块提供了可直接运行的工业工程优化建模交互案例，无需提前配置本地 Python 或求解器，打开网页即可动手调整参数、观察求解过程与敏感性变化。

## 11 套交互式 PySCIPOpt 建模案例

进入 [拓展学习](/learn) 页面，你可以浏览并运行以下 11 个专题案例：

- **基础评测示范**：`P001`（0-1 背包）、`P002`（人员指派）；
- **工业工程经典问题**：`IE-OPT-03`（容量约束设施选址）、`IE-OPT-04`（仓储装箱）、`IE-OPT-05`（排列流水车间调度）、`IE-OPT-06`（单周期随机库存优化）、`IE-OPT-07`（两仓三店辅料运输）、`IE-OPT-08`（铝材下料）、`IE-OPT-09`（巡检回路 MTZ 模型）、`IE-OPT-10`（带容量社区配送 CVRP）与 `IE-OPT-11`（单机总延误调度）。

### 使用小贴士

- **即开即用**：点击任意代码单元的「运行」或页面顶部的「全部运行」，首次触发时会自动加载浏览器端 Python 运行环境；代码单元共享同一个上下文命名空间，可随时点击「重置环境」还原。
- **独立结果核验**：每个拓展案例均内置小规模枚举或递归对照算例，方便你在修改模型公式后立即验证约束与目标是否建模正确。
- **教学数据说明**：案例所使用的需求量、工时、距离与成本矩阵均为**合成教学数据**，仅用于课程规律演示；迁移至实际工业分析时应补充真实假设与数据校准。
- **学习衔接**：各专题的推荐学习顺序与延伸方向请见 [课程学习路径](/docs/learning-path)。
