# 拓展学习指南

拓展学习提供可独立探索的优化建模课程案例，无需加入教学班级即可在浏览器内交互运行与修改参数。

## 11 个浏览器内交互式 PySCIPOpt 案例

拓展学习页（`/learn`）收录 `P001`、`P002` 与 `IE-OPT-03` 至 `IE-OPT-11`，涵盖背包、指派、容量约束设施选址、仓储装箱、排列流水车间、单周期随机库存优化、辅料运输、铝材下料、巡检回路（MTZ）、带容量配送及单机总延误。

- 运行方式：页面基于 Pyodide + SciPy HiGHS 兼容层（`web/public/runtime/pyscipopt.py`），按需加载后即可在单页内逐格运行或「全部运行」，支持实时修改参数对比最优方案并「重置环境」。
- 真值核对：各拓展 Notebook 均配有独立的小规模枚举或动态规划真值校验逻辑，点击具体课程卡片即可进入交互学习界面。
- 数据边界：上述案例数据均为**合成教学数据**，不代表企业真实运营绩效。开展对比试验时，应明确模型假设与决策变量作用域。
- 课程对应关系与建议学时写在 [课程学习路径](/docs/learning-path)。广义指派、带时间窗的车辆路径和并行机调度在学习路径中作了概念延伸说明，暂未单独设课。

## 练习与正式成绩的边界

拓展学习中的代码修改与运行结果仅保存在当前浏览器会话中，不会自动写入课程提交或课程成绩——**这里的运行一律只作练习，不计入正式成绩**。需要完成教师布置的计分作业时，请从顶栏进入「课程教学」，在对应班级作业页提交。
