# 拓展学习指南

拓展学习提供可独立探索的仿真案例与优化建模资源，无需加入教学班级。

## 三个仿真案例

| 案例 | 关注问题 | 可保留的记录 |
| --- | --- | --- |
| 检修工位与排队系统 | 工位数量、等待、利用率与随机波动 | CSV 和逐次重复的 JSON 实验记录 |
| 随机库存与服务水平 | 补货目标、缺货与运营成本 | CSV 配对实验结果 |
| 双工序生产线与缓冲 | 有限缓冲、加工后阻塞、在制品与吞吐量 | CSV 配对实验结果 |

数据均为合成教学数据。先阅读模型边界和参数单位，再设置两个方案进行对照；修改参数后重新运行，最后导出对应结果。保留随机种子与重复次数，避免从单次运行推断普遍结论。

## 优化建模资源

拓展区提供设施选址、装箱、排列流水车间与随机库存四个 PySCIPOpt Notebook，每个模型配有独立的小规模真值校验。点击具体资源会直接打开对应 Notebook；课程与拓展入口分别打开对应的实验文件。

“官方案例”页面提供 SCIP / PySCIPOpt 与 Gurobi 原始资源链接。请阅读各项目的说明和许可；本站运行环境默认使用 SCIP。

## 学习记录

仿真结果与 Notebook 修改保存在当前浏览器或下载文件中，不会自动形成课程提交或课程成绩。需要完成教师布置的作业时，从顶栏进入“课程教学”，按该作业要求单独提交。
