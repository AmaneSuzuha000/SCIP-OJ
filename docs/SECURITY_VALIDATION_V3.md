### 数据迁移

`supabase/migrations/010_submission_atomic_quota.sql` 重定义原有的 `compute_submission_attempt_no()` **同一个触发器函数**，不删除原始提交/成绩；给提交创建唯一索引和按时间查询索引。历史重复 (user_id, assignment_id, attempt_no) 需要先审计并修复，迁移才能建立唯一索引。

### 运维与公平规则

教师应告知学生本课程的正式提交次数约束，保留不计正式分的本地运行选项，并为网络不佳和辅助技术用户提供合理补救。429 不写入成绩；服务端故障记为 system_error，人工复判保留审计链。

禁粘贴只能起有限威慑作用，**不能当成作弊认定标准**。离线代码相似性结果只供教师审查。试运行时应模拟同题两次快速提交、跨题限流、多人并发、超时、学生手动中断、重判在途等场景。
