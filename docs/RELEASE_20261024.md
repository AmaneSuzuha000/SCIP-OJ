# SCIP/LAB 课程工作台与可复核实验交付

本轮承接 UI 草稿 #24 与 IE-DES-01 独立验证器 #22，合成一个课程功能交付。正式作业评分公式、数据库权限、学生历史成绩均不随此次发布修改。

## 可使用的功能

- 统一的 SCIP/LAB 学生工作台、题目编辑区、教师控制台及三种仿真实验入口。
- 检修排队实验导出逐次重复 JSON；`python -m judge.ie_des01_reference <文件.json>` 用独立的最小堆事件调度实现重放全部指标与配对区间。
- 库存与生产线实验的百分数 CSV 与页面保持相同单位。修改参数后必须重新运行，才能导出新结果。
- 手机展开课程菜单后可访问案例、建模资源及学习指南；教师入口仍由既有权限判定控制。

## 本轮修复

1. 固定侧栏与主内容区的总宽度，防止桌面横向溢出。
2. 平板和手机题目工作区切换为单列，避免高优先级桌面 CSS 覆盖窄屏样式。
3. 修复侧栏返回题库时，局部 `history` 元素遮蔽浏览器 History API 导致的异常。
4. 修复库存、生产线 CSV 中把 0–1 小数标成百分数的问题。
5. 防止修改参数后继续导出上轮实验。检修、库存与生产线均执行此规则。

## 验收证据

- Python 独立重放、篡改拒绝、评分隔离与权限回归。
- Node 三个仿真核心、浏览器评分、考试限制、Worker 隔离、CSV 单位及导出状态回归。
- Chromium 检查桌面首页/编辑区、手机首页/编辑区、平板编辑区；每个关键视图检查横向溢出，展开手机课程菜单并检查匿名权限。
- Chromium 实际下载检修 JSON，调用独立 Python 验证器；修改工位数、重新运行、再次下载并重放。
- Chromium 运行库存与生产线案例并实际下载 CSV；检查修改输入后停止导出。
- CI 截图安装经过哈希核对的中文字体，避免无中文字体的方框截图通过验收。合并主线后继续运行 Chromium 检查。
- Docker 回归验证隔离 PySCIPOpt 执行、攻击探针与四份课程 Notebook 的独立 oracle。

具体通过与否以当前提交的 Actions 运行结果为准，不能以本文替代 CI。截图与浏览器下载在 `scip-lab-ui-preview` Actions artifact 中留存。
