# 工业工程《系统建模与仿真》精品案例平台 — 课程蓝图 v1

## 1. 产品定位（取代“只有刷题”的心智模型）

SCIP-OJ 的正式判题、成绩簿、身份核验和证据审计属于**教学基础设施**。上层是贯穿一个完整课程的“情境—系统抽象—模型—仿真—统计—决策—评价”案例体系。LeetCode 式代码区只是学习交互的一部分，并不决定课程内容。

### 不可混淆的三种产物

| 产物 | 用途 | 是否计入正式成绩 |
|---|---|---|
| 案例实验室（如 IE-DES-01） | 可视化概念验证与参数敏感性演示 | 否；纯本地练习 |
| OJ 练习 L1 | Python solve(instance) 的性质检查 | 否；浏览器反馈 |
| OJ 正式提交 L2 | 服务端可信隔离、私有测试、留痕 | 是；数据库与教师控制台 |

新案例不得仅因为出现在前端菜单就声称支持 L2。只有完成服务端评分协议、隐藏测试、防作弊门控、课程绑定和端到端验收后，才能开通正式提交。

## 2. 六层精品案例能力阶梯

1. **IE-DES-01 工位配置排队仿真（已部署，回归校验）**：实体、事件、资源、FCFS、输入分布、独立重复、CRN、95% 近似置信区间、方案比较。
2. **IE-MC-02 随机库存与服务水平（已实现本地实验，待课堂试讲验收）**：随机需求、蒙特卡洛、风险指标、补货策略、灵敏度。
3. **IE-DES-03 双工序制造产线（已实现有限缓冲与阻塞，待课堂试讲验收）**：串行/并行工序、阻塞、饥饿、WIP、瓶颈识别与产能实验。
4. **IE-LOG-04 AGV 物流与资源冲突（规划）**：离散事件、搬运与加工双资源、交通冲突、死锁诊断。
5. **IE-RAM-05 设备可靠性与维护（规划）**：寿命分布、故障、维修与可用度、维护政策。
6. **IE-OPT-06 动态调度与仿真优化（规划）**：随机扰动、重调度、仿真—优化闭环、基准与稳健性。

每例课程成品需包含真实情境说明、假设清单、实体/事件/状态与方程定义、数据字典、边界测试、基准策略、重复仿真、统计不确定性、敏感性/消融分析、讲义与教师答案，以及可审查的评分规则。

## 3. IE-DES-01 模型合同与检验原则

模型：到达间隔 iid Exp(mean=arrivalMean)，服务工时 iid Exp(mean=serviceMean)，FCFS、无限候车容量、同质并行检修工位，模拟从空系统启动。输入参数均为**合成教学数据，不是检修工厂实测数据**。

- 每次独立重复使用不同确定性种子；同一次重复中的 A 与 B 复用同一序列的到达与服务工时（common random numbers, CRN）。
- 指标：观察窗口 [warmup, horizon] 内工位忙碌时间、完成量、时间平均排队长度、时间平均在制品；平均等待基于观察窗口内到达的任务，允许其启动服务时间超过 horizon，以避免简单右截断造成低估。
- 报告跨重复实验平均值；配对差值 B−A 使用样本方差及 1.96 正态近似构造 95% 区间。**在重复次数较少或分布偏斜时，此区间未必有精确 95% 覆盖率**。课程正式报告可采用 t 临界值、更多重复或 bootstrap 并检查稳定性。
- 理论负荷率 rho = serviceMean/(arrivalMean * servers)。rho≥1 时无限时域 M/M/c 不存在有限稳态平均等待，但有限时域模拟仍有数值结果；系统不应将其解释为稳态。
- 当前教学模型不涉及铁路检修真实的跨线吊运、共享人员、搬运 AGV、检修序列与死锁，不能据此断言这些系统的真实产能提升。
- 相同实验输入与种子应产生一致的数据；CSV 导出方便学生在 Excel/Python 继续复核。

## 4. 后续质量 Gate

| Gate | 最低通过要求 |
|---|---|
| G0 课程目标 | 每例至少有一条可测量的概念/方法学习目标；不是把优化题换标题 |
| G1 模型有效性 | 逻辑单元测试；边界情景；与分析模型或独立实现交叉核对 |
| G2 统计有效性 | 预热/重复/随机数口径明确；报告区间、不确定性与反例 |
| G3 判题可信度 | 模型/代码/解释分维评分；隐藏测试与分数版本化；禁止客户端自报正式分 |
| G4 教学可用性 | 学生与教师真实账号 E2E；无障碍/手机端；断线恢复；可追溯成绩 |
| G5 教学效果 | 课堂前测/后测、完成率、常见误区、教师复核成本与课程反馈 |

## 5. 技术路线与安全冻结

- 保留现有 GitHub Pages + JupyterLite + Supabase + 隔离 Actions 执行。案例实验室初版仅静态资源，**不新增数据库权限、考生个人信息采集或成绩回写 API**。
- 当前 OJ L1 仍使用 Pyodide，不等于 PySCIPOpt 内核；JupyterLab 使用 xeus-python + PySCIPOpt。后续统一运行环境之前不宣称同一内核。
- 禁复制/粘贴只能做课堂提示，不能作为作弊证明。正式考试的关键是服务端授权、身份核验、私有测试、随机化、合理的人工复核与申诉。
- 正式教学使用前，仍需真实学生—教师 E2E、数据库权限与 Edge 版本核对、并发/失败重试、成绩版本化和申诉流程。此 PR 的案例功能不解除这些门槛。


## 6. 官方 Examples 接入与新增验证（2026-10-23）

- 官方入口：PySCIPOpt Tutorials、PySCIPOpt GitHub examples/finished、SCIP Doxygen Example Projects、Gurobi Modeling Examples。站点 `official-examples.html` 建立场景、官方源码和课程任务的明确对应，不复制外部代码。
- IE-MC-02：每天“期初收货→响应 Poisson 需求→检查日补货”，固定提前期、lost sales；成本定义为日末存量持有+未满足需求罚损+正订单固定成本，未计单位采购价。测试零需求、确定需求、守恒与同策略零差值。
- IE-DES-03：两工序串联、无限外部候车队、有限中间缓冲、blocking-after-service；按事件时刻积分 WIP、阻塞与资源加工时间。测试三任务手工情形、流量守恒、二工序忙闲互补与同策略零差值。
- 既有 IE-DES-01：增加 Erlang-C 稳态理论交叉验证（仅在稳定且长观察期做近似核对）。这三个案例均使用独立重复配对比较的近似 95% 区间。
- IE-OPT-03：原创 Python Notebook，静态单源容量约束选址模型，用独立小规模穷举对照 PySCIPOpt 最优值；区别于官方可分割运输的 FLP。
- 教师教学评分规范见 [课程实验与评价规范](课程实验与评价规范.md)。新案例的本地演示结果不写入正式课程成绩。

## 7. 原创 PySCIPOpt 模型范例扩展

新增仓储装箱、排列流水车间和单周期随机库存优化三份 Notebook，均含逐个模型变量和约束定义、可执行代码、独立组合枚举或数学计算 oracle。其结果是确定性/场景数学优化的课堂例题，不等于本站随机离散事件仿真的绩效。课程说明保持 L2 私有判题仅支持已正式接入协议的 P001/P002。
