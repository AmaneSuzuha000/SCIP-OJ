# 判分协议（已冻结 · 2026-10-21）

适用于 scip-oj GitHub Pages MVP。

## 政策

1. **只做 L1**（浏览器内判分）；L2（PR/Actions）后补。
2. **多实例**：对 N 个实例（默认 3）分别评分，**总分 = 算术平均**（四舍五入到整数）。
3. **通过提示**：`score >= 90` 显示通过；不影响以后 L2 政策。
4. **对外文案**：L1 分数仅练习反馈，可被本机篡改，不作正式成绩。

## 技术要点（实现时遵守）

- 统一 `solve(instance) -> {status, objective, solution}`
- 分项：格式 / 可行性 / 整数性 / 目标 gap（部分分）
- 防硬编码：性质验证 + 多 seed；禁止只比对打印值
- `judge/` 与题面 `meta.json`（含 eps、weights、n_instances_l1、pass_score）
