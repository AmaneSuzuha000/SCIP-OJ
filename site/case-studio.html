TEACHING ASSIGNMENT / IE-DES-01

从一键运行，到能独立核验的课程实验

先作预测，再用固定协议实验，最后解释反例与工程约束。以下是可交付的课堂学习任务，不计入 L2 正式成绩。

01 / 实验前预测

先不运行，算负荷率

计算 ρ＝平均工时 ÷（平均到达间隔 × 工位数）。分别判断 A/B 是否满足 ρ < 1，并预测等待时间方向。

02 / 模型逻辑验证

用微型算例手算

三件任务：到达 0、0.5、1 分钟，服务时长 2、2、1 分钟。手算单工位与双工位的排队开始时间，再核对独立参考实现。

03 / 统计比较

不要挑最好的一次

把重复数由 5 改为 30、100，比较 B−A 的均值和区间。若区间跨过零，不能据此断言 B 更优；思考单个种子为何不够。

04 / 运营决策

把成本纳入判断

假设每工位每小时固定成本为 C，每件等待一分钟的代价为 P。构造比较两方案的成本表达式，并解释模型未覆盖的跨线搬运与工人约束。

可复核的实验记录

完成实验后导出 JSON，保留每次独立重复的输入种子、A/B 原始指标与配对差。教师使用标准库 Python 独立复算，检查随机流、队列事件、窗口指标和置信区间。

MODEL VALIDITY / TEACHING NOTES

一份像样的仿真实验报告，应回答什么？

01 / 建模边界

先定义系统

实体是检修任务，资源是并行工位，队列规则为先到先服务（FCFS）。不包含运输、设备故障、工人技能、优先级或跨线死锁。

02 / 输入与假设

辨认随机性

泊松到达对应指数到达间隔；检修时长独立且服从指数分布。这是教学假设，不应未经验证就代入真实检修现场。

03 / 实验设计

让比较公平

每次重复生成一套随机到达和服务工时，A/B 两方案复用同一套工作量（共同随机数），再对 30 个差值估计置信区间。

04 / 验证与决策

识别结论边界

比较等待、工位利用率、产出与在制品；评估增加工位的成本。区分有限时域仿真与长期稳态，不将单一随机种子的结果当规律。

课堂探究题

  1. 保持到达过程不变，将方案 B 从 3 个工位改为 4 个工位，边际等待收益如何变化？
  2. 如果平均检修工时增加 25%，基准方案可能发生什么？理论负荷率能否解释？
  3. 将重复次数由 5 提高到 50，区间宽度如何变化？为什么不应只比较两次模拟结果？
  4. 真实转向架检修存在运输、起重和共享工人时，本模型可能低估哪些等待或死锁风险？
