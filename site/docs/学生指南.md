# 学生指南

## L1：浏览器练习（不作正式成绩）

1. 打开站点题单，进入题目。
2. 阅读题面，理解 `solve(instance)`。
3. 点「提交评分（L1）」：对多个随机实例评分后取**算术平均**；≥ **90** 提示通过。
4. **L1 分数仅练习反馈**，可被本机篡改，**不作正式成绩**。

当前 MVP 按钮跑的是内置 demo 求解器；把真正作业代码交上去请走 L2。

## L2：正式提交（PR + Actions）

1. Fork 本仓库（或在有写权限的分支上作业）。
2. 新建分支，放入：

   `submissions/<你的 GitHub 登录名>/<题目ID>.py`

   例如：`submissions/AmaneSuzuha000/P002.py`  
   文件内必须定义 `solve(instance)`。

3. 向 `main` 开 Pull Request（改动需触及 `submissions/**`）。
4. 等待 **L2 Grade** Action：机器人在 PR 下评论平均分与是否通过。
5. **计入成绩认 L2 评论/产物中的分数**，不认浏览器 L1。

详见 `submissions/README.md`。
