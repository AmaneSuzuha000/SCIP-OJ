# 课程建模案例集

本目录收录工业工程《系统建模与仿真》课程的 11 套交互式 PySCIPOpt 教学案例，全部案例均使用合成教学数据。

- **在线学习入口**：<https://amanesuzuha000.github.io/SCIP-OJ/learn>

## 案例清单

1. **01_P001_knapsack_PySCIPOpt.ipynb** — 0-1 背包问题与容量约束建模
2. **02_P002_assignment_PySCIPOpt.ipynb** — 人员与任务一对一指派优化
3. **03_IE_Facility_Location_PySCIPOpt.ipynb** — 容量约束设施选址与产能分配
4. **04_IE_Bin_Packing_PySCIPOpt.ipynb** — 仓储装箱与最少箱数配置
5. **05_IE_Flow_Shop_PySCIPOpt.ipynb** — 排列流水车间生产调度（Makespan）
6. **06_IE_Stochastic_Inventory_PySCIPOpt.ipynb** — 两阶段场景法随机需求库存优化
7. **07_IE_Transportation_PySCIPOpt.ipynb** — 两仓三店辅料整数运输优化
8. **08_IE_Cutting_Stock_PySCIPOpt.ipynb** — 一维铝材下料与母材最小化
9. **09_IE_TSP_MTZ_PySCIPOpt.ipynb** — 巡检回路与 MTZ 破圈建模
10. **10_IE_CVRP_PySCIPOpt.ipynb** — 带载重约束的社区店配送路径（CVRP）
11. **11_IE_Single_Machine_PySCIPOpt.ipynb** — 单机顺序调度与总延误最小化

> 各案例可在课程网站中直接运行与调整参数，仅用于课堂学习与练习验证，不作为课程正式评分依据。修改 `.ipynb` 源文件后请运行 `node scripts/gen-lessons.mjs` 同步前端课程模块。
